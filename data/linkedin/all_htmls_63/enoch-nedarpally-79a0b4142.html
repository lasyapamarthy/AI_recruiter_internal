The Call Stack is a mechanism in JS Engine that keeps track of function calls and their execution contexts (ECs). It ensures that the code runs in the correct order and that every function gets executed and removed in the correct sequence. Think of it like a stack of books 📚 , the last book you put on top of the the stack is the first one you take off. Similarly, the Call Stack works on the Last In, First Out (LIFO) principle, making sure that the last function called is the first one to execute. ⚙️ Role of the Call Stack The main task of the Call Stack is to manage the order and control of Execution Contexts. There are two types of Execution Context, Global Execution Context and Function Execution Context. Global Execution Context (Global EC): Global EC is created and pushed to call stack as soon as the JS engine starts running a program. Function Execution Context (Function EC): Every time a function is called, a new execution context is created for that function Each Function EC is pushed onto the call stack when a function is called, and it’s deleted/popped off the stack when that function finishes execution or encounters return statement.
