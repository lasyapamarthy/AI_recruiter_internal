Simple things like using lazy loading, smaller image formats (like WebP), and tools like Cloudinary can really make a difference. It’s not just about code it’s about the experience we give to users. 2️⃣ What are some real-world use cases for debouncing and throttling? ✅ Both debouncing and throttling are essential tools for optimizing performance in JavaScript applications, especially in high-frequency events like typing, scrolling, or resizing. 💠 Debouncing is perfect when you need to wait until the user stops an action, preventing excessive function calls (e.g., in search inputs). 💠 Throttling helps by limiting the number of times a function is executed, making sure your app remains responsive even during continuous events (like scrolling). 3️⃣ How Does a CDN in React? ✅ A Content Delivery Network is a network of servers strategically located around the world, designed to deliver content (images, videos, stylesheets, JavaScript, etc.) to users as quickly as possible. Here’s a step-by-step breakdown of how it works: 💠 Distribution of Servers: A CDN has multiple edge servers located in different geographical locations These servers' cache and store copies of your website’s static content (like images, CSS files, etc.). 💠 User Requests Content: When a user visits a website, instead of fetching the content from the main server their request is automatically routed to the nearest edge server in the CDN network. 💠 Content Delivery from Nearest Server: The edge server closest to the user serves the requested content. This reduces the time it takes to deliver the content because the user’s request doesn’t have to travel as far. 💠 Caching Content: Static assets are cached at the edge server. If the content has been requested before, the edge server can deliver it without fetching it from the main server again. This improves performance and reduces server load. 4️⃣ Which one would you choose for a new React project and why CRA or Vite? ✅ For a new React project, I would choose Vite over Create React App. Since CRA is a reliable and easy-to-use tool for building React applications. While Vite stands out as the modern alternative due to its faster build times, smaller production bundles, and use of ES modules and es-build results in a smoother development experience, especially for larger projects. 5️⃣ What is Webpack? ✅ Webpack plays a critical role in the React development process by bundling, optimizing, and managing dependencies. It enhances performance with features like code splitting, tree shaking, and hot module replacement.
