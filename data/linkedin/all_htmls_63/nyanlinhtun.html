Here’s what makes it special: ✨ Key Features: 🎥 Real-Time Video Streaming: Live video feed via ESP32-CAM for precise tactical control. 🤖 Smart Combat System: A servo-powered battle hammer triggered manually or automatically when opponents are detected within 30cm. 🛡️ Defensive AI: Color-based opponent detection and evasion strategies. 💥 Touch-Sensitive Armor: Damage detection using limit switches, triggering a 30-second “recovery mode” when hit. 🌈 Visual Feedback: An 8x8 LED matrix displays dynamic patterns and red alerts during damage. ⌨️ WebSocket Control: Responsive remote control via a Python-based server for keyboard operation. 🔧 How We Built It: Core Hardware: Dual ESP32 boards for camera operations and robot control, integrated sensors, and a dual-motor drive system. Software Architecture: WebSocket server, real-time video streaming, and complex state management for battle conditions. Battle Logic: Sophisticated state machines, emergency protocols, and autonomous defensive/offensive behaviors. Control Interface: Intuitive keyboard-based control with real-time video integration. ✨ What’s Next? While Battle Bots PvP is already packed with cool features, we’re excited to explore integrating Neural Drive’s brainwave technology into the platform in the future.
