PostPost Optimizing UI performance with react hooks - 1. Using useRef() instead of useState() : As a beginner in reactjs, we generally use useState to store and keep track of variable values. Instead of useState, If we start using useRef - this will not trigger a re-render when the value changes. In useState, every time the value changes-> the dom gets updated and then it will trigger a re-render. useState works efficiently for small UI components but for large UI components it will lead to slow performance. 2. Memoizing the UI component to avoid unnecessary re-renders : In React hooks, to avoid unnecessary re-renders we can use useMemo() and useCallback(). By using useMemo(), we can control when and how UI components should re-render. 3. Using lazy loading to render the images in react : If you are working with a large codebase that has to render several images at once, we cannot wait till all the images get loaded. By using lazy loading, we render all the images in the viewport and then we can pass it to DOM. hashtag#react hashtag#reactjs hashtag#ui hashtag#frontend hashtag#performanceoptimization PostPost Essential ways to announce new features in UI: 1.
