After hearing about MCP, I wanted to see how it could handle the challenge of fetching fresh stock and financial data directly in an LLM workflow. Using Node.js, I built a custom MCP server to gather relevant market information. In a short photo walkthrough (attached), I demonstrate two approaches: 1. Without MCP: My browser-based LLM couldn’t fetch accurate, up-to-date stock prices—it kept defaulting to data from October 2024. 2. With MCP: The new server steps in and retrieves live data for both stock quotes and company financials, enabling better comparisons and more useful insights. The same held true for financial data and balance sheet of the companies. If you’re curious, feel free to check out my GitHub repo (link below) for details on how I set this up.
