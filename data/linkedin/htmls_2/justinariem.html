Especially with thousands of items 😵‍💫 💡 The Fix? Use smarter data structures. Try this with a Set: function isIntersect() { const set = new Set(target); return source.some(item => set.has(item)); } Now you’re down to O(n + m). That’s a massive performance boost, especially for large arrays. 📌 Key Takeaway: Don’t blindly trust .includes() in nested loops. Use Set, Map, or an index object for faster lookups!
