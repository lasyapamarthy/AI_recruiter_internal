Here's my solution! Problem Statement: Implement a Queue using an Array with the following operations: 🔹 1 x → Push 'x' into the queue. 🔹 2 → Pop an element from the queue and print it. If the queue is empty, return -1. Example: 🔹 Input: 1 2 1 3 2 1 4 2 🔹 Output: 2 3 Explanation: 1️⃣ 1 2 → Enqueue 2 → Queue: {2} 2️⃣ 1 3 → Enqueue 3 → Queue: {2, 3} 3️⃣ 2 → Dequeue → Popped: 2 → Queue: {3} 4️⃣ 1 4 → Enqueue 4 → Queue: {3, 4} 5️⃣ 2 → Dequeue → Popped: 3 → Queue: {4} My Approach: ✅ Used front and rear pointers for enqueue and dequeue operations. ✅ Implemented a circular queue using modulo division % data.length. ✅ Made it a dynamic queue by doubling the capacity when full. ✅ Copied elements starting from front to ensure correct order. Time & Space Complexity: ⏳ Time Complexity: enqueue(), dequeue(), isEmpty(), and front() → O(1) (Amortized for dynamic resizing). 💾 Space Complexity: O(N) for storing elements. Worst case: O(2N) due to dynamic resizing when capacity doubles. 🔥 Key Learnings: 1️⃣ Circular queues optimize space usage compared to simple linear arrays. 2️⃣ Dynamic resizing helps prevent queue overflow. 3️⃣ Efficient element copying ensures the queue maintains order after resizing. 🛠 Next Steps: I plan to explore Linked List-based Queue Implementation for further optimization. 🚀 A big thanks to Raj Vikramaditya for the structured DSA practice sheet! 🙌 hashtag#DSA hashtag#Queues hashtag#CodingPractice hashtag#ProblemSolving hashtag#DynamicQueue hashtag#FullStack hashtag#Programming hashtag#StriversSDEsheet hashtag#TakeUForward 🚀 Activate to view larger image, Show all posts ExperienceExperience Tata Elxsi logo Tata ElxsiTata Elxsi Full-time · 3 yrs 1 moFull-time · 3 yrs 1 mo Hyderabad, Telangana, IndiaHyderabad, Telangana, India Software EngineerSoftware Engineer Jul 2022 - Mar 2025 · 2 yrs 9 mosJul 2022 to Mar 2025 · 2 yrs 9 mos Developed a Battery Track and Trace system to track the lifecycle and movement of battery cells across the supply chain, ensuring real-time monitoring and compliance with safety regulations.
