It switches you to your previous branch. Instead of typing it all out, you can just say "-". "git checkout jcutler-my-favorite-branch" becomes "git checkout -". I even have an alias set up for git checkout so it becomes "gco -" AND you can extend this with "git merge -" to merge the last branch you were on, or "cd -" to switch to your previous directory. 2. git bisect It's the most underrated debugging tool. When something that WAS working starts breaking, run "git bisect start." It will use binary search to figure out the exact commit that broke it in lg(n) tries. Because it uses binary search, it can find the bad commit across 1000+ commits in just 10 tries. Use git checkout HEAD@{1.week.ago} to go back in time and easily find the "good" commit. Take this even further with "git bisect run {script}" which will automate the whole process for you as long as you have a test you can run it against. 3. git log -G "regex" This finds all commits throughout time matching the regex or string you provide. Great for finding when a pattern was introduced, changed, and why.
